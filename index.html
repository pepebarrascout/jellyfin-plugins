Pepe Barrascout · Plugins para Jellyfin

Un único repositorio para todos mis plugins de Jellyfin. Añádelo una vez y cada plugin, con todas sus actualizaciones, aparecerá automáticamente en el catálogo de Jellyfin.

URL del repositorio

Panel → Plugins → Administrar repositorios → +

Manifest https://pepebarrascout.github.io/jellyfin-plugins/manifest.json

Esta URL es la misma página donde estás ahora, terminada en /manifest.json. Si la landing se sirve desde otro dominio (por ejemplo en tu propio servidor), el botón copiará la URL correspondiente a ese dominio automáticamente.

Plugin de estadísticas de música para Jellyfin. Registra reproducciones de audio en una base de datos SQLite propia (sin tocar la BD de Jellyfin) y genera informes Top 50 y Bottom 50 por canción, artista, álbum y género en múltiples ventanas temporales. Permite crear listas de reproducción y programar su publicación.

Cómo instalar

  1. En Jellyfin, ve a Panel de control → Plugins → Repositorios.
  2. Pulsa el botón + para añadir un nuevo repositorio.
  3. Asigna un nombre (por ejemplo pepebarrascout plugins) y pega la URL del manifest de arriba.
  4. Guarda. En el catálogo de plugins aparecerán todos mis plugins, con sus versiones compatibles según tu Jellyfin (10.11 o 12.x).
  5. Instala el que quieras. Las actualizaciones futuras llegarán solas a través del catálogo.

Compatibilidad

Cada plugin incluye versiones para Jellyfin 10.11.x y para Jellyfin 12.x cuando aplica. En el catálogo, Jellyfin solo muestra las versiones compatibles con tu servidor (según targetAbi). No tienes que hacer nada manual para filtrarlas.

Los badges junto a cada plugin indican qué ramas de Jellyfin tiene versiones publicadas: Jellyfin 12.x Jellyfin 10.11
